Project Title
SarkaarSaathi – AI-Powered Government Assistant for Bharat


❗ Problem Statement
Millions of Indian citizens face difficulty accessing government schemes due to:

Complex language and legal jargon
Lack of awareness about eligible schemes
High rejection rates due to incorrect or missing documents
No guidance after rejection

👉 Result:
Time wasted
Benefits lost
Frustration, especially in rural areas


💡 Solution
SarkaarSaathi is an AI-powered platform that simplifies government processes by:

Helping users discover relevant schemes
Validating documents before submission
Generating appeals for rejected applications

👉 It provides a complete end-to-end solution — from discovery → validation → approval.


🔥 Core Features (3 Flows)

1️⃣ Benefit Hunter (YojanaMitra)
👉 User enters:
Age
Income
State
Occupation
👉 System:
Matches with relevant government schemes
Shows benefits + eligibility
🎯 Outcome:
User discovers schemes they didn’t know existed


2️⃣ Document Validator (DastaavezCheck)
👉 User:
Selects service (Scholarship / MSME / License)
Uploads required documents
👉 System:
Checks validity using logic + OCR
Shows:
✅ READY
❌ NOT READY
🎯 Outcome:
Reduces rejection chances before applying


3️⃣ Appeal Generator (NyaySaathi)
👉 User:
Uploads rejection letter OR enters text
👉 System:
Explains rejection in simple language
Generates a professional appeal letter
🎯 Outcome:
Helps user reapply and get approval
